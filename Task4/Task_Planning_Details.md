# Планирование разработки: Высокоуровневые задачи по системам

**Дата:** 2026-07-06  
**Горизонт:** MVP 6 месяцев + Post-MVP 6 месяцев (итого 12 месяцев)

---

# Цель проекта

Разработка системы оформления депозитов через Интернет-банк и публичный сайт с последующей автоматизацией распространения процентных ставок между внутренними и внешними системами банка.

Проект разделён на два этапа:

- **MVP** — запуск оформления депозитов через Интернет-банк и сайт.
- **Post-MVP** — внедрение сервиса централизованного распространения ставок (Rate Distribution Service).

Будут реализованы:

- Интернет-банк для оформления депозитов;
